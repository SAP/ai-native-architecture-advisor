How it works

Conversation-driven architecture.

No forms, no checklists. You describe the business scenario; the Advisor asks only the questions that change the architecture and builds the brief as you go.

01

Describe the scenario

Tell the Advisor who the users are, what the problem is, and any constraints. It reads the context — no rigid intake form.

02

Back-and-forth refinement

Explore the agentic opportunity, answer related architecture questions together, and shape a useful recommendation with a path toward the North Star.

03

Brief generated, ready to share

Markdown + visual HTML report. Ask for a re-run or update as the conversation evolves. The Markdown is always the source of truth.

What gets produced

Three files. One folder.

Each scenario gets a folder in SAP AI Native Solutions, with a shared README index to find earlier proposals. Generated content is excluded from Git by default.

Solution Brief

Architecture Proposal

Layer-by-layer direction: User Experience → Process → Foundation → Platform. Solution stack table. Open items folded into each layer.

<scenario>-solution-brief.md
Reasoning Log

Internal Audit Trail

Maturity mappings, inferences, decisions and why they were made. Kept separate from the brief so the proposal stays clean.

<scenario>-reasoning-log.md
Visual Report

HTML Presentation

One self-contained HTML file that opens directly in a browser. The Advisor regenerates it after Markdown changes; no server or live file connection is required.

Grounded in SAP architecture

Built on the official North Star.

Use North Star's vision and four layers, AI Golden Path approach guidance, and SAP Architecture Center implementation patterns to reimagine your use case.

Intent-driven engagement

Conversational engagement layer

Explore a useful Joule interaction and the broader intent-driven opportunity, while retaining specialist applications and making prerequisites explicit.

MCP Access

Governed SAP access via MCP

Reuse governed business APIs and MCP tools, or identify missing capabilities. A central MCP gateway is a choice when justified, not a prerequisite for every agent.

GenAI Hub

Governed model access

Solution-controlled LLM calls use generative AI hub in SAP AI Core. SAP-managed embedded AI is consumed through its supported product interface.

SAP Runtime

Supported SAP deployment

Choose SAP BTP Cloud Foundry, Kyma or a supported product-managed runtime. Address identity and operational telemetry, with audit needs considered separately.
